# Graphs

A website for visualizing graphs.

## Requirements

- [Node.js](https://nodejs.org) with [yarn](https://yarnpkg.com/).

## Quick start

### Install dependencies

```sh
yarn install
```

### Dev serveur

```sh
yarn dev
```

The site will be available on <http://localhost:5173/>.

### Build

```sh
yarn build
```

### Preview build

```sh
yarn preview
```

The site will be available on <http://localhost:4173/>.
